> Java 17 · Spring Boot · Spring Security · React · MySQL · WebSockets · JWT · Razorpay · Gemini AI

A multi-tenant SaaS platform for hospitals, banks, and colleges to manage queues and appointments in real time.

- 🔐 JWT + BCrypt + RBAC with 4 user roles (Super Admin, Org Admin, Staff, User)
- ⚡ Real-time queue sync using Spring WebSockets (STOMP protocol)

- 🏗️ Layered architecture with Spring Data JPA, Hibernate, and isolated multi-tenant org management
